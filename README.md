# Auto 8

A responsive car gallery website built as a frontend practice project.

## Live Demo

https://amir8mamadi.github.io/Auto8-project/

## Technologies

- HTML5
- CSS3
- Bootstrap 5

## Features

- Responsive design
- Persian RTL layout
- Custom typography
- Responsive navigation
- Car category sections
- Car showcase cards
- Contact section
- Mobile-friendly layout

## Responsive Design

The website is designed to work across desktop, tablet, and mobile screen sizes.
